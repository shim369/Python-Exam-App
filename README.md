# Python 3 エンジニア認定実践試験 模擬試験アプリ

Streamlit で動く、Python 3 エンジニア認定実践試験の模擬試験アプリです。
1回あたり40問・制限時間75分で、正答率70%以上で合格です。

## 必要なもの

- [uv](https://docs.astral.sh/uv/)
- Python 3.14(`.python-version` で指定しています。インストールされていなければ uv が自動で取得します)

## セットアップ

```bash
cd Python-Exam-App
uv sync
```

`.venv/` に仮想環境が作られ、`uv.lock` に固定されたバージョンの依存パッケージ(Streamlit、開発用の pytest)がインストールされます。

## 起動

```bash
uv run streamlit run app.py
```

ブラウザで http://localhost:8501 が開きます。

## 使い方

1. **開始画面**：受験する回を選んで「試験を開始する」を押します。各回の前回スコアが一覧で表示されます。
   - 「受験履歴」で過去の記録を選んで「結果を見る」を押すと、そのときの結果画面をいつでも開き直せます。
2. **出題画面**：問題が1問ずつ表示されます。
   - 4つの選択肢から1つ選び、「次へ →」で進みます。最後の問題では「採点する」が表示されます。
   - 「← 前へ」で戻ると、選んだ解答が残っていて選び直せます。
   - 進捗(例: 問題 12 / 40)と残り時間が表示されます。時間切れになると自動で採点されます。
   - 選択肢の並び順は、受験のたびにシャッフルされます(試験中は変わりません)。
3. **結果画面**：正答数・正答率・合否、章ごとの正答数、全問の一覧(自分の解答・正解・解説)が表示されます。「間違えた問題だけ表示する」で絞り込めます。
   - 「間違えた問題を解き直す」を押すと、間違えた問題(未解答を含む)だけを解き直せます。時間制限はなく、1問ずつ「答え合わせ」で正誤と解説を確認できます。選択肢の並び順はシャッフルし直されます。解き直しの結果は受験履歴に記録しません。

受験結果(日時・回・正答数・章ごとの正答数・問題ごとの解答と選択肢の並び順)は `results/history.json` に追記保存されます(git の管理対象外です)。

## ディレクトリ構成

```
Python-Exam-App/
├── .claude/commands/new-exam.md  # /new-exam コマンド (次の回を作る手順)
├── .gitignore                    # textbook/ や .venv/、results/ などを除外
├── .streamlit/config.toml        # テーマ設定 (ダークモード、見出しのフォントサイズ)
├── app.py                        # アプリ本体 (開始画面 → 出題画面 → 結果画面)
├── exam_core.py                  # 章ごとの出題数などの定数、問題・履歴の読み書き
├── exams/
│   └── exam-01.json              # 問題データ (1回分 = 1ファイル)
├── results/history.json          # 受験履歴 (受験すると作成される)
├── scripts/validate_exams.py     # 問題データの検証スクリプト
├── tests/                        # AppTest によるアプリのテスト
├── textbook/                     # 教科書のテキスト (git の管理対象外)
│   ├── 1.1/                      #   「章.節」フォルダ。中の 1_1_1.txt などが本文
│   └── ...                       #   1.1 〜 18.2
└── pyproject.toml / uv.lock      # 依存関係 (uv で管理)
```

### 教科書 (`textbook/`) について

教科書のテキストは git で管理していません。リポジトリを clone した場合は、`textbook/` に「章.節」フォルダ(`1.1/` 〜 `18.2/`)を置いてください。

- アプリでの受験だけなら、教科書は不要です。
- 検証スクリプトと `/new-exam` には必要です。フォルダがある章・節だけを出題範囲として扱います。

## 問題データ

`exams/` 内の `exam-*.json` が自動で一覧になります。JSON を追加するだけで回が増え、アプリのコードを変更する必要はありません。

ファイル全体は `{"title": "第1回", "questions": [...]}` の形式で、各問題は次の形式です。

```json
{
  "id": "exam01-q01",
  "chapter": 3,
  "section": "3.3",
  "topic": "この問題が問う論点を1行で",
  "question": "問題文",
  "code": "問題文に付くコード。なければ null",
  "choices": ["選択肢1", "選択肢2", "選択肢3", "選択肢4"],
  "answerIndex": 0,
  "explanation": "正解の理由と、他の3つが誤りである理由"
}
```

### 次の回を追加する

Claude Code でこのディレクトリを開いて、次を実行します(`textbook/` に教科書が必要です)。

```
/new-exam
```

教科書を章ごとに読んで40問を作問し、実行確認・検証スクリプト・テストまで行って `exams/exam-NN.json` を追加します。手順は `.claude/commands/new-exam.md` にあります。

## 検証とテスト

```bash
# 問題データの検証
uv run scripts/validate_exams.py

# アプリのテスト (AppTest)
uv run pytest -q
```

検証スクリプトは全回の JSON について次の点を検査し、節ごとの出題済み回数の一覧も出力します。エラーがあると終了コード 1 で終わります。教科書はデフォルトで `textbook/` を参照します。別の場所にある場合は `--textbook <ディレクトリ>` で指定してください。

- 40問あること、章ごとの出題数が規定どおりであること
- 選択肢が4つで重複がないこと、answerIndex が 0〜3 であること、必須項目が埋まっていること
- id が全回を通して一意であること、出題範囲(教科書にある節)から出題していること
- 過去の回との重複(問題文・コードの完全一致はエラー、類似度が高いものは警告)

テストでは次の点を確認します。テスト中の受験履歴は一時ファイルに書き込むので、`results/history.json` は変更されません。

- 開始 → 40問を最後まで進める → 採点 → 結果画面の表示
- 「前へ」で戻ったときに解答が保持されていること
- 選択肢の並び順が試験中に変わらないこと
- 時間切れで自動的に結果画面へ進むこと
- 開始画面の受験履歴から結果画面を開き直せること(解答の詳細がない古い記録も含む)
- 間違えた問題だけを解き直し、答え合わせができること

## 依存パッケージを変更したとき

```bash
uv add <パッケージ>            # 実行時の依存
uv add --dev <パッケージ>      # 開発用の依存
```

`pyproject.toml` と `uv.lock` が更新されます。
